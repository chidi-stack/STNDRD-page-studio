# STNDRD Page Studio

Next.js editor and public renderer for STNDRD Coach landing pages. Sections come from Webflow via DevLink. Page content is stored in Supabase.

**Start here:** [HANDOFF.md](./HANDOFF.md) — what is built, how to run it, and what is left.  
CSS export notes: [DEVLINK.md](./DEVLINK.md).

```bash
cp .env.example .env.local
npm install
npm run dev
```

Editor: [http://localhost:3000/editor](http://localhost:3000/editor). Published pages: `/[slug]`.
